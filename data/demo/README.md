# Синтетический контрольный пример

Три условных события, **10 объектов на одном чипе `DEMO_CHIP3`** и четыре возможных заказа. Имена начинаются с `DEMO_`. Для остальных двух чипов в этом небольшом примере выданы только метаданные разделения. Снимков и истинной карты воды нет. Стоимости активов, уязвимость, даты и ставка БРЕ — учебные допущения.

`assets.geojson` и `exposure.csv` содержат одинаковый портфель разных классов, стоимости и уязвимости. Точки условны и не обозначают реальные объекты. `chip_footprint.geojson` задает условную область учебного фрагмента.

`candidates.geojson` содержит четыре полигона без holes площадью 1,000; 2,000; 3,000 и 1,000 км². `DEMO_O2` — вогнутый полигон: его площадь меньше площади ограничивающего прямоугольника. `candidate_units.csv` рассчитан по фактическому покрытию точек этими контурами. Перекрытия сохранены для проверки однократного учета пользы. Подробности — в [правилах геометрии](../../docs/ORDER_GEOMETRY.md).

Версия: `demo-1.1`. Пересоздать портфель, контуры и связи: `python -m tools.make_demo`. Проверить: `python -m tools.audit_data --data data/demo --geometry` (после установки `requirements.txt`).

Нет рекомендованной корзины. Запуск с указанными вручную ID показывает только арифметику цены.
