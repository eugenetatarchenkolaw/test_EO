# Синтетический контрольный пример

Три условных события, четыре условных актива и четыре заказа. Имена начинаются с `DEMO_`. Снимков и истинной карты воды нет. Стоимости активов, уязвимость, даты и ставка БРЕ — учебные допущения.

`candidate_units.csv` содержит намеренно пересекающиеся **условные** множества для теста арифметики объединения. Они не получены из геометрии. Поэтому геометрии заказов не выданы и demo нельзя использовать для проверки GIS-пересечений. Точки `assets.geojson` условны и не обозначают реальные объекты.

Нет рекомендованной корзины. Запуск с указанными вручную ID показывает только арифметику цены.
