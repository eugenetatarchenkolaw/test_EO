# Справочные данные

[asset_types.csv](asset_types.csv) — десять типов с фиксированными учебными V/q из «Постановка_кейса_3.docx». Здесь нет координат и готового портфеля. Команда самостоятельно размещает по одному объекту каждого типа на выбранном официальном S1-чипе.

[evidence](evidence) — числовые таблицы научных публикаций для графиков. Они не являются данными обучения, прогнозами или результатами FloodValue.

Спутниковые файлы получают из [официального Sen1Floods11](https://github.com/cloudtostreet/Sen1Floods11). Организатор не выпускает отдельный конкурсный архив. [Описание данных](../docs/DATA.md) · [Форматы результатов](../docs/CONTRACTS.md).
