# Данные

- [demo](demo): условные таблицы, пригодные только для проверки интерфейсов и арифметики.

Конкурсные спутниковые данные в эту версию не входят. [Описание входов](../docs/DATA.md), [порядок выпуска](../docs/DATA_RELEASE.md), [форматы](../docs/CONTRACTS.md).
