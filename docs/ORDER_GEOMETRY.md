# Площадь и геометрия заказа

Согласованное условие кейса: **одна заказываемая зона имеет площадь не менее 1 км² и представляет собой один полигон без внутренних вырезов (holes)**. Допускаются вогнутые, вытянутые и другие ломаные контуры. Квадратная форма не обязательна. Контур должен быть замкнутым, без самопересечений и вырожденных участков. Несвязанные зоны оформляются отдельными позициями, каждая — от 1 км².

Минимум 1 км² относится к каждой позиции заказа, включая архивную, оперативную и новую съемку в учебном сценарии. Это условие задачи, а не установленный здесь коммерческий минимум или требование ПП № 840. Условия реального поставщика, доступная полоса съемки и возможность вырезки продукта проверяются отдельно. Тип и разрешение данных в базовом расчете берутся из каталога; выбор конкретного аппарата от команды не требуется.

## Площадь по контуру

Оплачивается площадь самого полигона. Его ограничивающий прямоугольник, выпуклая оболочка, число объектов внутри и площадь чипа не подменяют площадь заказа. Для вогнутой зоны эти величины могут существенно различаться. Из площади контура нельзя вычитать воду, незастроенные участки и другие внутренние области: holes в этом сценарии не допускаются.

В базовом протоколе GeoJSON хранит координаты WGS84: долгота, широта. Вершины переводятся в равновеликую проекцию **EPSG:6933**, после чего площадь полученного полигона делится на 1 000 000 для перевода м² в км². Ребра контрольного контура — отрезки между преобразованными вершинами. Этот способ расчета фиксируется для всех команд; измерение площади непосредственно в градусах недопустимо. Для территории за пределами области применения проекции или с пересечением 180-го меридиана организатор заранее объявляет другой протокол.

Минимум проверяется **до округления**: 0,9996 км² не становится допустимым заказом после округления до 1,000. В `area_km2` затем записывается площадь с точностью 0,001 км² по принятому `ROUND_HALF_UP`. Вычислительный допуск проверочного модуля — 10⁻⁹ км², только для погрешности преобразования координат. Это не допуск на уменьшение зоны на сотни квадратных метров.

В demo полигон `DEMO_O2` вогнутый: его фактическая площадь — 2,000 км², ограничивающий прямоугольник — 2,500 км². Цена рассчитывается по 2,000 км². Все четыре контура находятся в [candidates.geojson](../data/demo/candidates.geojson).

## Каталог и авторские контуры

В основном сравнимом расчете команды выбирают `candidate_id` из выданного каталога. Геометрии этого каталога могут иметь произвольный допустимый контур — слово «тайл» в имени `pricing_tiles.csv` не требует квадрата.

Команда может исследовать собственный способ формирования зон дополнительной съемки. Такие контуры и их экономику показывают отдельным экспериментом, с тем же минимумом площади и запретом holes. Самостоятельно менять геометрию уже выданного `candidate_id` нельзя: изменятся оплачиваемая площадь и покрытие. Для включения авторских зон в основной каталог организатор должен заранее опубликовать общий для всех порядок их регистрации и оценки. Пока такого порядка нет, обязательный план остается выбором из фиксированного каталога.

## Объекты и перекрытия

В учебном примере **10 объектов на одном условном чипе `DEMO_CHIP3`**, с разными классами, стоимостью и уязвимостью. [exposure.csv](../data/demo/exposure.csv) и [assets.geojson](../data/demo/assets.geojson) согласованы по идентификаторам и значениям. [chip_footprint.geojson](../data/demo/chip_footprint.geojson) показывает условный контур этого фрагмента; снимка и истинной маски воды у него нет. Для конкурсного набора ориентир — около 10 объектов на чип, без требования искусственно одинаковой плотности везде.

Для точечного demo объект считается покрытым, если лежит внутри полигона или на его границе (`covers`). Связи [candidate_units.csv](../data/demo/candidate_units.csv) рассчитаны по этим геометриям. Архивный контекст не добавляет покрытие текущего ущерба. Один объект, попавший в несколько выбранных зон, учитывается в пользе один раз; стоимость отдельных заказов считается по каждой оплачиваемой позиции.

## Проверка

```bash
python -m pip install -r requirements.txt
python -m tools.audit_data --data data/demo --geometry
```

Проверяются тип Polygon, отсутствие holes и самопересечений, минимум площади, соответствие `area_km2` контуру и точечные связи покрытия. В режиме сдачи `validate_submission` выполняет эту проверку каталога автоматически, в том числе с `--tables-only`. Для площадных единиц организатор задает `coverage_rule=organizer_verified_units` и отдельно проверяет пространственные доли; проверка контуров и площади сохраняется.

Документация используемых операций: [Shapely — геометрии и предикаты](https://shapely.readthedocs.io/en/stable/manual.html), [Rasterio — преобразование геометрии](https://rasterio.readthedocs.io/en/stable/api/rasterio.warp.html). Восстановить синтетические геометрии и портфель можно командой `python -m tools.make_demo`. Она не генерирует прогнозов и не выбирает заказы.
