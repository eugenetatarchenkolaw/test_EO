# Правила кейса

Краткая навигация по утвержденной «Постановка_кейса_3.docx». Полный текст постановки и «Критерии_кейса_3.docx» имеют приоритет над справочником.

## Общий обязательный результат

| Часть | Условие постановки |
|---|---|
| Данные | Официальный Sen1Floods11; получение и независимое разделение выполняет команда. Дополнительные открытые бесплатные источники — по выбору |
| Два метода | Пороговый baseline с бинарной маской и самостоятельный основной метод с вероятностями, маской и неопределенностью. Основной метод не сводится к смене порога |
| Сравнение | Одни независимые данные, метки и валидные пиксели; IoU, F1/Dice, Precision, Recall и число пикселей |
| Обоснование | Хотя бы один контролируемый эксперимент без настройки по test; при дополнительных данных — сравнение S1-only с расширенным вариантом |
| Объекты | На одном S1-чипе ровно 10 случайных точек, по одному заданному типу; фиксированные V/q, seed и правило размещения |
| Ущерб | Для всех 10 объектов EL = p × V × q по исходным вероятностям основного метода; неопределенность, приоритеты, прокси-проверка и чувствительность |
| Заказы | Собственные Polygon без holes и самопересечений, каждый ≥ 1 км² до округления; оплачивается площадь по контуру |
| Экономика | A/B/C на одной карте и одном портфеле; общий каталог B/C; стоимость данных C в пределах объявленного командой бюджета |
| Продукт | Интерфейс оператора с пересчетом бюджета без обучения и изменения исходных прогнозов/портфеля |
| Воспроизводимость | Стандартные результаты, весь код и используемые модели/веса в GitVerse; инструкции обучения и inference на другом официальном S1-чипе |

Для baseline вероятностный выход, калибровка и отдельные ущерб/A/B/C не обязательны. Улучшение одной метрики и сложность архитектуры сами по себе не определяют оценку.

## Независимость и смысл результата

Координаты объектов получают случайно в валидной области исходного S1 без использования прогнозов обоих методов, ущерба и ручных тестовых меток. При попадании в nodata повторяют генерацию по зафиксированному правилу. Один портфель сохраняется во всех стратегиях.

Train/validation/test или эквивалентное разделение документируются. Пересечения событий и соседних окон исключают либо явно учитывают и обосновывают. Пороги, модель, калибровку и параметры нельзя выбирать по итоговой проверке. Опубликованный авторами split допустим с указанием версии и ограничений.

Метка воды Sen1Floods11 сама по себе не отделяет временное затопление. Если постоянная вода не исключена обоснованным временно корректным способом, подпишите результат «карта воды». Дополнительные сведения, возникшие после события, не используют как доступные при имитации оперативного решения.

## Самостоятельная работа

Команда выбирает архитектуру, параметры, показатель неопределенности, способ создания и отбора зон, дизайн и среду. Собственные контуры — часть обязательного решения. Разрешены дополнительные эксперименты, но они не заменяют обязательный расчет.

Готовые split, координаты, зоны, прайс-лист поставщика, скрытая выборка, эталонные предсказания и модели организатором не выдаются. Жюри может запустить обучение по инструкции, применить сохраненный метод к другому официальному S1-чипу и изменить бюджет. Код, модель и веса размещаются в GitVerse; внешний адрес весов этого требования не заменяет.

Широкая закупка B сверх лимита обозначается как контрфактическая. Пустой план C допустим при отсутствии подходящих заказов в пределах бюджета. Покупка снимков не означает предотвращение физических потерь; без новых наблюдений ее эффект оценивают сценарно.

Оценка выполняется по [утвержденным 20 критериям](EVALUATION.md). Дополнительных автоматических штрафов или порогов качества справочник не устанавливает.
