# Подготовка к двум методам

По постановке обязательны **пороговый baseline** и **самостоятельный основной метод**. Основной метод не сводится к изменению порога baseline: он дает вероятности, согласованную бинарную маску и оценку неопределенности. Для baseline достаточно бинарной маски и метрик сегментации; отдельные вероятности, калибровка и экономика не обязательны.

Архитектуру, признаки, способ обучения и параметры команда выбирает самостоятельно. Сложность модели не дает отдельных баллов. Важны проверяемый результат и способность объяснить его ограничения.

## Что требует собственный эксперимент

До итоговой проверки зафиксируйте разбиение, параметры обоих методов, пороги и конфигурацию основного метода. Статистики подготовки данных получают по train; настройку и калибровку выполняют на train/validation. Метки −1 не входят в метрики как класс суши.

Проведите хотя бы один содержательный контролируемый эксперимент, объясняющий выбранную конфигурацию. При дополнительных источниках отдельно сопоставьте S1-only и расширенный вариант. Оба метода сравните на одних независимых валидных пикселях по IoU, F1/Dice, Precision, Recall и их числу. [Полный протокол проверки](VALIDATION.md).

Значение в [0,1] еще не доказывает надежность вероятности. Опишите способ ее получения и проверьте соответствие наблюдаемой доле воды. Для выбранного показателя неопределенности проверьте связь с ошибками или нестабильностью, затем объясните его перенос к объектам и зонам. Конкретный показатель и способ исследования не предписаны.

## Воспроизведение

В GitVerse сохраняются код получения и подготовки данных, разбиения, обоих методов, экспериментов, выбора порогов и inference. Для обучаемой модели нужны код обучения, конфигурация, модель и веса в GitVerse, включая при необходимости Git LFS или релизы. Одной сторонней ссылки на веса недостаточно.

Colab допустим, но среду выбирает команда. README должен позволять применить зафиксированный основной метод к другому официальному S1-чипу, в том числе без оптики. Пересчет бюджета использует уже полученные вероятности и тот же портфель; повторное обучение для него не требуется.

`requirements.txt` этого справочника относится только к чтению метаданных и обслуживанию материалов. Зависимости собственного решения команда фиксирует отдельно.
