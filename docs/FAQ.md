# Частые вопросы

**Что главнее: DOCX или GitHub?** Выданные «Постановка_кейса_3.docx» и «Критерии_кейса_3.docx». Репозиторий — дополнительный справочник.

**Где получить конкурсный архив, split и скрытый test?** Их нет. Команда получает официальный Sen1Floods11, выбирает данные и документирует независимое разделение. Открытость меток не разрешает настройку по test.

**Можно ограничиться пороговым методом?** Нет. Нужны пороговый baseline и самостоятельный основной метод; смена порога не считается вторым методом. Нейросеть при этом не обязательна.

**Нужны ли вероятности и экономика baseline?** Не обязательны. Baseline сдает бинарную маску и метрики. Обязательные вероятности, неопределенность, ущерб и A/B/C относятся к основному методу.

**Обязателен Sentinel-2?** Нет. Дополнительные открытые бесплатные источники разрешены, но решение должно работать только по S1. При их использовании сравниваются S1-only и расширенный вариант.

**Откуда взять объекты и зоны?** Команда случайно размещает ровно десять точек заданных типов/V/q на одном S1-чипе, независимо от прогнозов, ущерба и тестовых меток. Зоны также формирует сама: Polygon без holes, минимум 1 км² до округления, цена по контуру.

**Что делать с объектом за пределом бинарной воды?** Считать EL по исходной вероятности p, а не обнулять по маске. Для отсутствующей оценки используются статус и пустые поля по [формату](CONTRACTS.md).

**Можно заменить pVq другой моделью?** В обязательном расчете десяти объектов — нет. Альтернативная модель допустима отдельным дополнительным экспериментом.

**Где публиковать код и веса?** В GitVerse команды, включая код обучения и используемую модель/веса. Сторонняя ссылка на веса не заменяет их размещения там. Этот GitHub содержит справочные материалы.

**Можно заранее обучить модель?** Да. Сохраненные веса применяются без перенастройки; жюри также должно иметь возможность запустить обучение по инструкции. Пересчет бюджета не требует обучения.

**788,64 руб./км² — официальный тариф?** Нет, это сценарная ставка из постановки. Нормативная методика не подтверждает конкретную цену поставщика. [Источники и допущения](PRICING_PP840.md).

**Допустима другая трактовка ПП № 840?** Да, с конкретными положениями, источниками и воспроизводимым альтернативным расчетом рядом с базовым. Отличие само по себе не считается ошибкой.

**B дороже бюджета, а C пуста — это допустимо?** B сверх бюджета обозначается как контрфактическая. Пустой C допустим при отсутствии подходящих заказов в пределах бюджета. Остальные результаты и сравнение сохраняются.

**Нужны одинаковые панели и слайды?** Нет. Общими являются результаты и критерии. Среду, дизайн и оформление выбирает команда.

**Есть готовый проверяющий скрипт сдачи?** Нет. Команда разрабатывает проверки и публикует их код. Список проверяемых условий есть в [протоколе](VALIDATION.md); GitHub Actions проверяет только целостность этого справочника.
