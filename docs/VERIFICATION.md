# Что проверено в публичном комплекте

Проверка версии 1.0 выполнена 20.09.2026. Это проверка учебных материалов и инструментов, а не испытание модели FloodValue на конкурсных данных.

| Проверка | Результат и границы |
|---|---|
| Автоматические тесты | 16 тестов пройдены: ручной пример цены, граница 90 дней, скидки и их ограничения, пересчет корзины, нулевой тариф с основанием, неверные числа и ID, бюджет, суммы ущерба, ранги, split, nodata и контрольный GeoTIFF |
| Вводный ноутбук | Схема ipynb валидна; все 6 кодовых ячеек выполнены последовательно в IPython, включая вывод SVG |
| Полный Jupyter/Colab | Ноутбук успешно выполнен целиком через nbclient в GitHub Actions: [запуск № 1](https://github.com/eugenetatarchenkolaw/test_EO/actions/runs/35519991477), шаг Execute introductory notebook. Локальная среда ограничивала запуск ядра через сокеты; прямой запуск в веб-интерфейсе Colab отдельно не проверялся |
| Документы и файлы | Проверены относительные ссылки, синтаксис Python, чистота публичного ноутбука, SVG и заголовки CSV |
| Графики | Все три графика отрисованы и визуально проверены; числа сверены с указанными таблицами/формулами |
| Закрытые материалы | В составе публикации нет исходных DOCX/PDF, расшифровки встречи, экспертного ответа, закрытого ноутбука, обученных весов или скрытых меток |
| Научная модель и экономика на реальном событии | Не проверялись: конкурсные снимки и портфель не предоставлены. Результаты и экономия не выдуманы |

Повторить локальную проверку:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m tools.audit_data --data data/demo
python -m tools.check_repository
```

`check_repository` не делает сетевой запрос по каждой внешней ссылке. Библиографические источники проверялись отдельно; недоступность части официальных загрузок отражена в [нормативной справке](PRICING_PP840.md). Перед соревнованием организатор дополнительно выпускает и проверяет [конкурсный набор](DATA_RELEASE.md).
