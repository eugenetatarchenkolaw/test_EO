# Пустые формы результатов

CSV содержат только обязательные заголовки из раздела III постановки. GeoJSON — пустые FeatureCollection, `strategy_plans.json` — пустые списки A/B/C. Эти заготовки не содержат координат, прогнозов, цен или выбранных заказов и не являются готовой сдачей.

`run_metadata.json` и `source_manifest.json` оставлены пустыми: обязательное **содержание** паспортов перечислено в [форматах](../../docs/CONTRACTS.md), а вложенную структуру определяет команда. Их нужно заполнить собственными параметрами и источниками; пустой JSON не выполняет требования.

Растры, маска baseline, метрики обоих методов, результаты экспериментов и интерфейс создаются кодом команды. Имена файлов метрик не фиксированы — укажите их в README и паспорте запуска. Дополнительные поля разрешены.

В `procurement_plan.csv` сохраняются строки **B и C** с ключом `(strategy, candidate_id)`; для A строк нет. Пустой C не означает, что можно не сдать каталог, сравнение и остальные обязательные результаты.
